# Security policy

This developer-preview release has known unresolved issues listed in [docs/security.md](docs/security.md). It has not been independently audited. No production-support or response-time commitment is made.

For a newly discovered vulnerability, use the repository's **Security → Report a vulnerability** feature if private vulnerability reporting is enabled. Otherwise, request a private reporting channel from the maintainer without including exploit details, credentials, or customer data in a public issue.

Include the affected commit, configuration, impact, and minimal reproduction using disposable data. Never test against other people's installations without permission.
